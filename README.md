# Student Performance Prediction

This is a Machine Learning project that predicts a student's final exam score based on academic and lifestyle-related factors.

## Features Used

- Study Hours
- Attendance Percentage
- Previous Score
- Assignments Completed
- Sleep Hours

## Machine Learning Model

The project uses a **Random Forest Regressor** to predict the student's final score.

## Technologies Used

- Python
- NumPy
- Pandas
- Matplotlib
- Scikit-learn

## Machine Learning Workflow

1. Data generation and preparation
2. Feature and target separation
3. Train-test split
4. Model training
5. Prediction
6. Model evaluation
7. Feature importance analysis

## Model Performance

The model achieved an R² score of approximately **0.81** on the test data.

## Example

The model can predict an expected final score using a student's study hours, attendance, previous score, completed assignments, and sleep hours.

## Note

The dataset used in this project is synthetically generated for learning and demonstration purposes. It is not intended for making real-world decisions about students.
